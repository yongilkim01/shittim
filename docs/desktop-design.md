# 데스크톱 디자인 적용

사용자가 제공한 성·호수 데스크톱 시안의 Dock과 파일 관리자/브라우저 창을 기준으로 조정했다.

| 영역 | 조정 |
|---|---|
| Dock | 기존 52px 높이·30px 아이콘 유지, 네 모서리 절단·안쪽 세로선·비활성 앱 테두리·활성 청록색 면 |
| Dock 끝 | 구분선 뒤 설정·휴지통. 설정 좌클릭은 Control Center, 우클릭은 App Launcher. 휴지통은 Nemo에서 열기 |
| 앱 목록 | 설치된 앱과 기존 사용자 고정 순서 유지. 시안 속 미설치 앱을 추가하지 않음 |
| 공통 제목 표시줄 | 24px 높이, 원형 버튼 배경 제거, 청록색 `− / □ / ×` |
| Nemo | 9pt 모노스페이스, 작은 아이콘, 압축된 툴바·탭, 어두운 사이드바, 채워진 파란 폴더와 종류별 표식 |
| Chrome | 별도 색상 테마의 탭·툴바·주소창 배경 및 아이콘. 브라우저 개인 설정 파일은 직접 편집하지 않음 |

노트북에서 한 번 실행한다. 현재 설치된 Shittim 제목 표시줄 설정이 있을 때만 함께 갱신하며 새 플러그인을 설치하지 않는다. 기존 사용자 설정은 설치기의 백업/병합 흐름을 따른다.

```bash
cd ~/projects/shittim
git pull --ff-only
bash scripts/apply-desktop-design.sh
```

Nemo는 파일 작업을 마친 뒤 모든 창을 정상적으로 닫고 다시 연다. 기존 폴더별 보기 설정이 저장되어 있으면 그 폴더는 기존 크기를 유지할 수 있다. 툴바의 아이콘 보기/확대·축소로 변경할 수 있다. 공통 제목 표시줄 자체를 설치하지 않았다면 [제목 표시줄 설치](titlebars.md)를 먼저 따른다.

Chrome의 탭·주소창은 GTK CSS로 전체를 제어하지 못하므로 [공식 Chrome 색상 테마 형식](https://developer.chrome.com/docs/extensions/develop/ui/themes)으로 별도 제공한다.

1. Chrome에서 `chrome://extensions`를 연다.
2. 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 선택한다.
3. 저장소 안의 `assets/chrome-theme` 폴더를 선택한다. 기본 경로는 `/home/yongil/projects/shittim/assets/chrome-theme`이며 실제 저장소 위치에 맞춘다.

테마는 색상만 포함하며 스크립트/접근 권한/웹페이지 수정 코드를 포함하지 않는다. 원래 테마로 돌아가려면 Chrome 설정 → 모양 → 테마 초기화를 사용한다. 공통 hyprbars와 Chrome 자체 버튼이 중복되면 탭 바 빈 곳 우클릭의 **시스템 제목 표시줄 및 테두리 사용**을 켠다.

원본 파일 관리자와 브라우저는 디자인 시안이다. Nemo의 실제 메뉴/내부 레이아웃, Chrome의 탭 형태와 웹사이트 본문까지 이미지와 동일하게 재작성한 것은 아니다. 공통 제목 표시줄도 hyprbars의 실제 장식 영역이며 창 프레임의 절단 코너까지 추가하는 플러그인 패치는 포함하지 않았다. Dock/QML과 새 SVG는 로컬 Qt 렌더링으로 점검하고, 실제 GTK·브라우저·Hyprland 합성 결과는 노트북에서 확인한다.
