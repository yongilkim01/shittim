# Shittim Files

원본 데스크톱 시안의 파일 관리자 영역을 별도 QML 앱으로 구현한다. Nemo의 GTK 내부 배치를 바꾸는 방식에서 전용 파일 관리자로 전환했다. Nemo는 재귀 복사·이동의 충돌/진행 대화상자와 보조 탐색에 유지한다.

## 적용

새 설치는 `./install.sh`에 포함된다. 기존 노트북은 저장소 갱신 후 실행한다.

```bash
cd ~/projects/shittim
bash scripts/apply-desktop-design.sh
bash scripts/verify-files.sh
```

Dock의 파일 아이콘, 바탕화면 Home/Projects/Trash, 기본 폴더 열기와 `Super+E`는 Shittim Files로 연결된다. 별도 사용자 단축키 충돌은 유지한다. Super+E를 의도적으로 교체할 때만 `bash scripts/setup-desktop.sh --replace-bindings` 후 `hyprctl reload`를 실행한다.

기존 앱 등록·MIME·개인 Dock 설정은 설치기의 백업 경로에 보관한다. 개인 Dock의 `nemo.desktop`은 첫 등록 때만 새 앱으로 옮기며 나머지 순서·설정은 유지한다. 재실행으로 사용자가 다시 바꾼 고정을 강제하지 않는다. 이미 열린 Nemo 창은 그대로 남으므로 새 Dock 아이콘으로 연 창을 확인한다.

## 화면과 기능

기본 비율은 440×326, 사이드바 구분선 x=96, 본문 x=103, 파일 칸 55×74, 아이콘 32px, 파일명·사이드바 9px다. 기본 폭에서는 6열이다. 창 크기를 바꾸면 열 수와 본문 영역이 늘어나고 글자·아이콘 크기는 논리 픽셀 기준으로 유지한다. 기존의 전체 화면 0.8~1.5배 확대를 제거했으며 모니터 배율은 Qt가 처리한다. 통합 Home 탭, 얇은 절단 프레임과 절제된 발광을 유지한다. 자체 창 버튼과 프레임은 Qt Quick Shapes 벡터 경로로 그리며 `− / □ / × / 복원` 기호의 폭은 모두 16px, 선 굵기는 1.6px다. 제품에 예시 파일·장치·용량을 넣지 않는다.

실제 GIO 탐색, 탭 16개, 뒤로/앞으로/홈/상위 폴더, 경로 입력, 현재 폴더 이름 검색, 아이콘/목록 보기, 숨김 파일, 여러 파일 선택, 파일 열기, 새 폴더, 이름 변경, 복사/잘라내기/붙여넣기, 휴지통 이동과 원래 위치 복원을 제공한다. 아이콘 보기에서 파일 URI를 드래그해 내보내거나 폴더/본문에 드롭해 복사할 수 있다. 영구 삭제 버튼은 제공하지 않는다.

| 조작 | 동작 |
|---|---|
| 파일/폴더 더블클릭 | 기본 앱 실행 / 폴더 이동 |
| Ctrl/Shift + 클릭 | 추가 / 범위 선택 |
| Ctrl+L / Ctrl+F | 경로 입력 / 현재 폴더 검색 |
| Ctrl+T / Ctrl+W | 새 탭 / 탭 닫기 |
| Alt+← / Alt+→ / Alt+↑ | 뒤로 / 앞으로 / 상위 폴더 |
| Ctrl+C / Ctrl+X / Ctrl+V | 복사 / 잘라내기 / 붙여넣기 |
| F2 / Ctrl+Shift+N / Delete | 이름 변경 / 새 폴더 / 휴지통 이동 |
| Ctrl+H / F5 | 숨김 파일 / 새로고침 |
| 제목 빈 부분·탭 드래그 | 보조 키 없이 창 이동 |
| 가장자리·모서리 드래그 | 창 크기 조절 |
| `−` / `□` / `×` | 숨김 / 최대화·복원 / 닫기 |

숨김은 기존 창 서비스의 특수 워크스페이스 정책을 사용하고 Dock에서 복원한다. 최대화·복원도 같은 창 서비스에 Files 자신의 주소를 전달해 Hyprland의 maximized 모드를 전환한다. 사용자 설정에 앱의 maximize 요청을 무시하는 규칙이 있어도 동작하며 그 규칙을 변경하지 않는다. 버튼 아이콘은 실제 Hyprland 상태를 따라 `□`와 겹친 두 사각형으로 전환되고, 단축키로 최대화한 경우도 반영한다. 이동·크기 조절은 Qt의 시스템 창 요청을 사용하며 최대화 중에는 크기 조절 핸들을 비활성화한다. `org.shittim.Files` 전용 Hyprland 규칙으로 외부 hyprbars·테두리를 꺼 이중 제목 표시줄을 방지한다. 이 앱의 세 버튼에는 hyprbars 설치가 필요하지 않다. 다른 앱 장식은 [제목 표시줄](titlebars.md)을 따른다.

## 시스템 연결과 제한

- `shell/files.qml`은 독립 AppId/ShellId의 Quickshell 앱이다. 로그인 때 파일 창을 자동 실행하지 않는다. `files-client.py`가 사용자 런타임의 flock과 IPC로 기존 인스턴스에 경로를 전달한다. 여러 폴더는 탭으로 연다.
- GIO로 실제 파일·XDG 사용자 폴더·마운트를 읽고 폴더 변경 이벤트로 갱신한다. 디스크 폴링은 하지 않는다. 오래된 응답은 요청 번호로 무시한다.
- 저장소의 아이콘·배경은 절대 `file:` 주소로 읽는다. QML 설정 루트 밖의 `assets/`를 Quickshell 내부 상대 주소로 해석하지 않는다. Home·Projects는 같은 파란 폴더 계열을 사용한다.
- 파일명은 일반 텍스트다. 이름/URI 검증과 인수 배열을 사용하고 셸 문자열로 조합하지 않는다. 복사/이동은 기존 Nemo의 형식이 지정된 D-Bus API를 재사용한다. 접수 이후 진행·충돌 선택은 Nemo 대화상자가 담당한다.
- 파일명·탐색 기록을 Git이나 로그에 저장하지 않는다. 탭·선택·기록은 현재 프로세스 메모리에만 둔다.
- 폴더당 최대 20,000개, 작업당 최대 256개다. 한도·권한·연결 오류는 화면에 알린다. 메뉴의 **보조 앱 Nemo로 열기**로 전환할 수 있다.
- 휴지통·네트워크는 설치된 GIO/GVfs 지원 범위에서 탐색한다. 자격 증명이 든 URI는 받지 않는다. 원격 쓰기·마운트·인증 관리는 보조 Nemo로 연다. 휴지통 복원은 같은 이름이 있으면 덮어쓰지 않고 오류를 표시한다. `.desktop`은 실행 코드를 해석하지 않고 Nemo에 전달한다.

추가 패키지는 없다. 기존 Quickshell·Qt Quick·python-gobject·Nemo·GVfs·wl-clipboard를 사용한다. Qt 창 이동/크기 조절 메서드는 Qt 6.8 이상에서 지원되며 Quickshell 0.3.2 소스와 Qt 6.9 API를 확인했다.

## 검증

격리된 Linux 임시 폴더에서 실제 GIO 탐색·이름 변경·생성·휴지통 이동, Desktop Entry 특수문자 경로 실행과 IPC 클라이언트를 검사했다. Windows Qt에서는 FilesView를 렌더링하고 선택·탭·키 입력·버튼 신호를 검사했다. 실제 Hyprland 창 조작·Dock 복원, Wayland 드래그, Nemo 복사 대화상자·다중 모니터는 노트북에서 확인한다.

`FilesWindow` 전체 생성·표시와 크기 조절 핸들을 회귀 검사한다. `verify-files.sh`는 실제 Quickshell에서 이 창 전체를 로드하고 Dock 아이콘 4개·Home·Projects·배경 이미지 및 GIO 폴더 읽기를 함께 확인한다.

로컬 Qt 검사에서 100/125/150/200% 배율의 버튼 표시 폭과 창 확대 전후 고정 UI 크기를 확인했다. 실제 Hyprland의 GPU 표시와 상단 작업 영역은 노트북에서 확인해야 한다. Files 위에 숨긴 외부 제목 표시줄의 24px 예약 공간을 제거하려면 `bash scripts/setup-titlebars.sh --install-hyprbars`로 수정 플러그인을 다시 빌드한 뒤 Files 창을 닫고 다시 연다. 이 명령은 기존 hyprbars 사용 환경에서 실행한다.

최대화 때도 프레임 경로를 네 변에서 2.5px 안쪽에 둔다. 5px 발광 선의 절반이 창 밖으로 잘리지 않도록 하며, 최대화의 각진 형태와 작업 영역 크기는 유지한다. 100/125/150/200% 배율의 Qt 렌더링 검사에서 위·아래·왼쪽·오른쪽 테두리를 각각 확인한다.

```bash
bash scripts/verify-files.sh
python3 scripts/files-client.py "$HOME"
```

1. 실제 파일·한글 이름, 더블클릭·뒤로·새 탭·Ctrl+L·검색·스크롤을 확인한다.
2. 테스트용 폴더에서 생성·이름 변경·복사·붙여넣기·휴지통·복원을 확인한다. 같은 이름을 붙여넣어 Nemo 충돌 대화상자를 확인한다.
3. 제목/탭을 키 없이 드래그하고 모서리 조절, `□` 두 번, `−` 후 Dock 복원, `×`를 확인한다. 최대화하면 가운데 아이콘이 겹친 사각형으로 바뀌고 복원하면 `□`가 되는지, `Super+Up`으로 최대화·복원할 때도 반영되는지 확인한다.
4. Dock을 반복 클릭해 창이 중복 생성되지 않는지 확인한다. Ctrl+T는 같은 창의 새 탭이어야 한다.
5. 다른 배율의 모니터에서 글자·버튼·프레임을 확인한다. 시안과 비교할 때 창의 논리 크기를 같게 맞춘다.

파일명 목록이 없는 실행 상태 확인:

```bash
quickshell ipc --path "$PWD/shell/files.qml" call files status
```
